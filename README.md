# Hi, I'm Vincenzo

Engineer and software architect based in Rome. I lead technology at Poste Italiane,
where I have spent the last years building cloud-native platforms and enterprise AI.
I still write code every week, mostly in Go and Python.

What I work on: agentic systems and their memory, identity and authorization for
workloads and agents, retrieval and evaluation, Kubernetes.

## Projects

- **[aletheia](https://github.com/vmarchese/aletheia)**: multi-agent troubleshooting
  framework for SREs. A gateway daemon, specialist agents for Kubernetes, AWS, Azure,
  Prometheus, logs and network, MCP support, skills and persistent memory. Python.
- **[aegis-operator](https://github.com/vmarchese/aegis-operator)** and
  **[aegis-proxy](https://github.com/vmarchese/aegis-proxy)**: a JWT-based service mesh
  for Kubernetes. Identities and ingress policies as CRDs, a sidecar injected by a
  mutating webhook, identity federation with Vault, Entra ID and AWS. Go.
- **[autoskill](https://github.com/vmarchese/autoskill)**: optimizes agent skills in a
  loop. Claude Code proposes changes, an eval suite with an LLM judge scores them,
  git keeps or reverts. Python.
- **[grep_rag](https://github.com/vmarchese/grep_rag)**: a small experiment with a
  grep-based agent for RAG.
